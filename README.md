
# Filtrando Produtos com Java Streams

## Sobre o projeto
Projeto desenvolvido em Java para praticar o uso de Streams na manipulação de listas de produtos.

## Funcionalidades
- Filtrar produtos da categoria Eletrônicos.
- Selecionar produtos com preço inferior a R$ 1.000.
- Ordenar produtos pelo menor preço.
- Limitar o resultado aos 3 primeiros produtos.

## Tecnologias
- Java
- Stream API
- Programação Funcional

## Conceitos praticados
- Listas e objetos
- Lambda Expressions
- filter()
- sorted()
- limit()
- collect()

## Objetivo
Praticar a manipulação e filtragem de coleções utilizando Java Streams.
